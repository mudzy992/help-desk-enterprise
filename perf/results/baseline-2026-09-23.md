## 4. Kako se dobija pravi baseline

```bash
# 1. baza i aplikacija
psql "$DATABASE_URL" -f ops/sql/enable_pg_stat_statements.sql
psql "$DATABASE_URL" -f ops/sql/snapshot_db_stats.sql > perf/results/baseline.db-before.txt
cd backend && npm run build && node dist/src/main.js &     # API
node dist/src/worker.js &                                  # worker

# 2. mjerenje (puni profil; ili -e VU=800 -e DURATION=10m za lokalno)
k6 run -e BASE_URL=http://localhost:10001 perf/full.js

# 3. baza + log poslije testa
psql "$DATABASE_URL" -f ops/sql/snapshot_db_stats.sql > perf/results/baseline.db-after.txt
grep -E "db_queries_per_request|event_loop_lag_p95_ms|ws_clients_count" app.log > perf/results/baseline.app.log
```

Rezultat zamjenjuje ovaj dokument (`perf/results/baseline.md`) i popunjava red
"Baseline" u `PERFORMANCE_PHASE_PLAN.md` §7.
