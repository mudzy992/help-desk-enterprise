## Announcements split

Izdvojeno je:

- `components/announcements/announcement-archive.tsx` — archive query, loading/error/empty state i deep-link fokus;
- `lib/announcements/announcement-editor-model.ts` — draft mapiranje, deterministički početni schedule, role katalog i audience toggle.

Page zadržava manage list, pagination, publish/withdraw/report akcije i dialog orchestration. Editor zadržava save/preview side effecte i operation guard, dok su inicijalizacija i audience transformacije čisti modeli.

## Account notifications split

Izdvojeno je:

- `components/account/notification-preference-views.tsx` — availability upozorenja, Teams status i policy lock hint;
- `lib/notifications/notification-preference-view.ts` — stabilni email mode katalog i category i18n mapiranje.

Page ostaje owner load/save/reset/test lifecyclea, optimistic drafta, partial problema i query invalidacije. API ugovor nije promijenjen.

## Login split

Izdvojeno je:

- `components/auth/login-presentation.tsx` — value points i Microsoft brand mark.

Credential forma, autocomplete atributi, CAPTCHA/rate-limit stanje, provider odabir, MFA/must-change handoff i session sigurnosni tok ostali su netaknuti u `LoginPage`. Nisu promijenjeni input ID-jevi niti E2E entry-point markup ugovori.
