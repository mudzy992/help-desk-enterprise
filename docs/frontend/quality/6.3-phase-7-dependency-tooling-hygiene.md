- Vite: `5.4.21` → `8.3.5`;
- Vitest: `2.1.9` → `5.0.5`;
- `@vitejs/plugin-react`: `4.7.0` → `6.1.2`.

Time su zatvoreni:

- Vitest UI arbitrary file read/execute;
- Vitest mocker path traversal/code injection;
- Tinypool prototype-pollution/RCE advisories;
- Vite path traversal, filesystem deny bypass i launch-editor advisories;
- stari esbuild dev-server advisory;
- `source-map-js` advisory.

Frontend sada eksplicitno zahtijeva Node `>=22`, što odgovara aktuelnom CI Node 22 runneru i Vite 8 engine ugovoru.
