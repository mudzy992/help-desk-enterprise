## Stanja i ownership

Registry se oslanja na postojeće direktne testove za primjenjiva stanja:

- loading/empty/error/retry kroz query hookove i entity error komponente;
- stale refresh/race kroz managed announcements, settings i query hook testove;
- invalid/not-found kroz detail state resolver i page/detail modele;
- permission action visibility kroz route access, admin access i domenske view modele;
- URL round-trip kroz Assets, Problems, Changes, Services i Ticket query modele;
- fokus/keyboard/real layout kroz navedene Playwright ownere.

Backend permission enforcement namjerno nije dupliran frontend render testovima.
