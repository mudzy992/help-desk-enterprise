## Asset detail razlaganje

Iz composition pagea izdvojene su koherentne prikazne cjeline u:

- `components/assets/asset-detail-sections.tsx`;
- overview i metadata kartice;
- ticket prikaz;
- historija sa cursor pagination modelom i statusima učitavanja/greške.

`AssetDetailPage` ostaje owner route parametra, query orkestracije, mutacija, permisija, aktivnog taba i action sheet lifecyclea. Time poslovna orkestracija nije premještena u generički UI sloj.

Action availability je centralizovan u čistom `resolveAssetActionAvailability` modelu. Model direktno zaključava manage/delete permisije, assignable statuse i postojanje assignmenta.

Rezultat:

- composition page: **435 linija**;
- izdvojeni detail sections modul: **323 linije**;
- oba modula su ispod application ceilinga od 500 linija.

Cilj od 320 linija za page nije umjetno ostvaren premještanjem međusobno povezane query/mutation orkestracije. Primarni acceptance limit od 500 je ispunjen bez uvođenja prop-drilling wrappera.

## Import workflow razlaganje

Import history tabela, status tone mapping i empty/loading prikaz izdvojeni su u:

- `components/assets/asset-import-history.tsx`.

Workflow tranzicije i apply guardovi izdvojeni su u čisti model:

- `lib/assets/asset-import-model.ts`.

Model imenuje i direktno testira:

- setup korak;
- odabrani file korak;
- promijenjeni mapping korak;
- potvrdu;
- stale mapping blokadu;
- pending blokadu;
- empty apply blokadu;
- all-or-nothing conflict blokadu.

`AssetImportPanel` zadržava file input, preview/apply/discard side effecte i njihove race-safe lokalne state updateove. Rezultat:

- import panel: **495 linija**;
- history view: **94 linije**;
- workflow model ostaje mali, čisti `lib` modul;
- nijedan novi niti postojeći FA2A produkcijski modul nije iznad 500 linija.
