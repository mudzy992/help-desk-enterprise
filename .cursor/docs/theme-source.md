# [ARHIVIRANO] theme-source — stara dark-only paleta

> **Ovaj dokument više nije izvor istine.** Zadržan je samo kao istorijski zapis originalne
> dark-first palete; **ne koristi ga** za nove ekrane, tokene ni kontrastne odluke.
>
> Zamijenio ga je **[`.cursor/docs/theme.md`](theme.md)**, koji je implementacijski katalog aktivnog
> dizajn-sistema **Pulse** (tokeni, geometrija, palete `data-accent`, kontrast) i koji se drži uz kod:
> `frontend/src/index.css` + `frontend/tailwind.config.ts`.
>
> Hijerarhija izvora (važeća):
>
> 1. **Tematika:** `.cursor/docs/theme.md` (izvor istine je kod).
> 2. **UX / interakcija:** `Master UI-UX Design Constitution.md`.
> 3. **Živi dokaz:** `demo/` + Visual QA tabla u aplikaciji.
>
> Zašto je penzionisan: opisivao je isključivo tamnu temu i fiksne hex vrijednosti, pa je svaka
> izmjena u Pulse-u (svijetli mod, `data-accent` palete, radius/sjena kao tokeni) bila u direktnom
> sukobu s njim. Ostavljanje dva „mjerodavna" izvora je bilo gore od brisanja — zato je sadržaj
> zamijenjen ovom oznakom, a original ostaje u git istoriji.
